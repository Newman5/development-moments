# Development Moments

A small experiment in extracting reusable knowledge from real software
development work.

Instead of turning a long development conversation directly into blog
posts, tutorials, or courses, this project captures useful **moments**:
problems, decisions, commands, discoveries, mistakes, tests, and lessons.

Each moment can be assigned to one or more **destinations** — possible
future uses such as a blog post, tutorial series, course, or dev log.

The process is inspired by the same philosophy behind Recent Bookmarks:

**Find → Save → Review → Use**

Here that becomes:

**Work → Capture Moments → Organize → Review → Create**

## Current experiment

The first dataset comes from the development and release of Recent
Bookmarks v1.1.0.

Initial possible destinations include:

- Building Recent Bookmarks v1.1
- Are Bookmarks Broken?
- Linux Through Software Development
- Learning Software Development with an AI Pair Programmer
- GitHub Through a Real Software Project
- Shipping Real Software

These destinations are provisional. The goal is to let patterns emerge
from the captured moments before deciding what should become a blog
post, series, tutorial, or course.

## Structure

`_data/moments.yaml` is the source dataset.

Future destination folders may contain outlines, notes, drafts, and
published material derived from the moments.

## Principle

Capture first. Organize lightly. Review for patterns. Create only when
the material suggests something worth making.
